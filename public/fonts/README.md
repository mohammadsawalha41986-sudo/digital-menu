# Self-hosted webfonts

Every family here is licensed under the **SIL Open Font License 1.1**, which
permits redistribution and self-hosting provided the licence travels with the
files. The full text is in `OFL.txt`.

| Family | Scripts | Used for |
|---|---|---|
| Cairo | Arabic + Latin | Contemporary Arabic sans — the default body face |
| Tajawal | Arabic + Latin | Geometric Arabic sans — minimal and modern themes |
| Amiri | Arabic + Latin | Naskh serif — heritage and luxury headings |
| El Messiri | Arabic + Latin | Arabic display — bold and expressive headings |
| Playfair Display | Latin | Editorial Latin serif, paired with Amiri |
| Inter | Latin | Neutral Latin sans, paired with Cairo or Tajawal |

Files are the `woff2` subsets Google Fonts serves, kept at their original
unicode ranges so a browser downloads only the script it is about to draw.
They are regenerated by `node scripts/fetch-fonts.mjs` and **committed**, so a
build never needs network access.
